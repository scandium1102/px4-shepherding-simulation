# Evidence scope

## Included

- A public overview figure for the PX4, MAVROS, Gazebo, and Python-controller integration.
- The documented target software stack and finite-state-machine design.

## Not claimed

- Flight tests on a physical vehicle.
- Measured tracking, endurance, safety, or collision-avoidance performance.
- A completed vision detector or autonomous field deployment.

The repository deliberately omits local workspaces, simulator build artifacts, credentials, and machine-specific configuration.
